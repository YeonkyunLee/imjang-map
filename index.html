① 토큰 만들기

GitHub에 개인 계정(YeonkyunLee)으로 로그인된 상태여야 합니다. 다른 계정이면 GitHub 오른쪽 위 프로필 → Switch account / Add account로 바꾼 뒤 ①을 다시 누르세요.
①을 누르면 이름·권한(Contents 읽기/쓰기)·기간(1년)이 채워진 GitHub 화면이 열립니다. Repository access에서 "Only select repositories" → imjang만 고르고 Generate → 토큰 복사 → 돌아와서 ② → 저장. 토큰은 이 브라우저에만 저장됩니다.
