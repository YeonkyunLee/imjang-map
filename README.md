# imjang-map

임장 노트(private 저장소 `YeonkyunLee/imjang`)를 폰에서 지도로 보는 정적 앱. 이 저장소에는 코드만 있고 데이터는 없다.

- 지도: Leaflet + OpenStreetMap (카카오 키 발급 후 카카오맵으로 교체 예정)
- 데이터: GitHub API로 노트 목록·본문을 읽어 frontmatter 파싱. `유형`이 있는 노트가 장소, `moc` 태그 노트는 지역 노트
- 토큰: fine-grained, imjang 저장소 Contents 권한. 앱 설정(⚙)에 입력하면 그 브라우저에만 저장
- 캐시: 받은 노트를 blob sha 기준으로 브라우저에 저장, 바뀐 노트만 다시 받음. 통신이 안 되면 캐시로 표시

## 쓰기 (노트 단위 커밋)

- 상세 시트: 상태·평가 변경(다녀옴으로 바꾸면 방문일 자동), 메모 추가(`## 임장 메모` 끝에 `- 날짜 시각 내용`)
- 위치 지정/수정: 버튼 → 지도 누르기 또는 "내 위치로"
- 새 장소: 지도 길게 누르기(PC는 우클릭) → `<지역>/<이름>.md` 생성
- 충돌: 다른 곳에서 먼저 수정됐으면 최신본을 받아 같은 변경을 다시 적용

## 오프라인 · 설치 · 동선

- 홈 화면에 설치(PWA). 서비스워커가 앱 화면·라이브러리와 본 적 있는 지도 타일(최대 3000장)을 캐시
- 통신이 안 될 때 저장하면 대기열에 쌓고 화면에는 바로 반영. 연결되면(또는 1분마다) 순서대로 커밋. 실패한 건은 설정 화면에 내용과 함께 남김
- 동선: `임장 계획` 노트의 지역별 `추천 동선` 줄(과 그 아래 들여쓴 줄)의 `[[링크]]` 순서. 목록(☰)의 지역 옆 "동선" → 지도에 번호·점선, ◀ ▶로 한 곳씩 이동

## 사진

상세의 📷 → 촬영 또는 갤러리 선택(여러 장 가능). 긴 변 1600px JPEG로 줄여 `첨부/<장소>-<시각>.jpg`로 커밋하고, 임장 메모에 `- 날짜 시각 (메모 칸 내용) ![[첨부/…jpg]]` 한 줄을 추가. Obsidian에서 그대로 보인다. 오프라인이면 대기열에 보관(브라우저 저장 공간 한도 안에서)했다가 연결되면 전송.

## 정비구역 경계

- 상단 "구역" 버튼: 서울시 의제처리구역 중 정비 관련(재개발·재건축·재정비촉진지구·가로주택 등) 경계를 표시. 구역을 누르면 이름, 장소 상세에는 그 장소가 속한 구역
- 자료: 서울 열린데이터광장 OA-20957 (`zones.json`, 키 불필요). 서울 밖은 없음. 해제·완료 구역이 남아 있거나 최근 지정분이 빠질 수 있음
- 갱신: 새 zip을 받아 `python tools/make_zones.py <폴더>/shp파일/UPIS_C_UQ181 zones.json "UQ181, YYYY-MM"`

## 좌표 채우기

좌표 없는 장소의 상세에서 "위치 후보 찾기" → 이름이 맞는 정비구역 경계(중심점)와, 설정에 카카오 JavaScript 키가 있으면 카카오 주소·장소 검색 결과를 지역 중심에서 가까운 순으로 보여줌. "보기"로 확인 후 "저장".

## 로컬 실행

```
python dev.py            # http://localhost:8000
```

localhost에서는 GitHub 대신 `dev.py`가 노출하는 로컬 노트 폴더(기본 `~/Documents/Ian_obsidian/임장`)를 읽는다.
