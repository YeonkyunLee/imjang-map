# imjang-map

임장 노트(private 저장소 `YeonkyunLee/imjang`)를 폰에서 지도로 보는 정적 앱. 이 저장소에는 코드만 있고 데이터는 없다.

- 지도: 카카오맵 JS SDK. JS 키는 `index.html`에 기본값으로 들어 있음(공개용 키, 카카오 콘솔에 등록한 도메인 `https://yeonkyunlee.github.io`에서만 동작). 설정(⚙)에서 다른 키로 바꿀 수 있음
- SDK를 못 받으면(오프라인 첫 실행·키 문제) 지도 없이 목록(☰)·상세만으로 동작
- 데이터: GitHub API로 노트 목록·본문을 읽어 frontmatter 파싱. `유형`이 있는 노트가 장소, `moc` 태그 노트는 지역 노트
- 토큰: fine-grained, imjang 저장소 Contents 권한. 앱 설정(⚙)에 입력하면 그 브라우저에만 저장
- 캐시: 받은 노트를 blob sha 기준으로 브라우저에 저장, 바뀐 노트만 다시 받음. 통신이 안 되면 캐시로 표시

왼쪽 패널(목록·필터·설정)은 왼쪽으로 밀어서 닫는다.

## 쓰기 (노트 단위 커밋)

- 상세 시트: 상태·평가 변경(다녀옴으로 바꾸면 방문일 자동), 메모 추가(`## 임장 메모` 끝에 `- 날짜 시각 내용`)
- 위치 지정/수정: 버튼 → 지도 누르기 또는 "내 위치로"
- 새 장소(임장할 곳): 오른쪽 아래 **＋ 추가** → 단지명·구역명·주소 검색(카카오 장소+주소)으로 고르거나 "지도에서 찍기"·"현재 위치". 이름·주소·유형(카테고리·이름으로 추정)·위치·가장 가까운 지역(3km 안)을 채우고 `<지역>/<이름>.md`를 `상태: 계획`으로 생성. 지도 길게 누르기(0.6초, PC는 우클릭)도 같은 화면
- 충돌: 다른 곳에서 먼저 수정됐으면 최신본을 받아 같은 변경을 다시 적용

## 오프라인 · 설치 · 동선

- 홈 화면에 설치(PWA). 서비스워커가 앱 화면·라이브러리·카카오맵 SDK를 캐시. 카카오 지도 타일은 CORS 헤더가 없어 서비스워커로 캐시하지 않고 브라우저 HTTP 캐시(6시간)에 맡김 — 그날 본 곳은 통신이 약해도 대체로 보임
- 통신이 안 될 때 저장하면 대기열에 쌓고 화면에는 바로 반영. 연결되면(또는 1분마다) 순서대로 커밋. 실패한 건은 설정 화면에 내용과 함께 남김
- 동선: `임장 계획` 노트의 지역별 `추천 동선` 줄(과 그 아래 들여쓴 줄)의 `[[링크]]` 순서. 목록(☰)의 지역 옆 "동선" → 지도에 번호·점선, ◀ ▶로 한 곳씩 이동

## 사진

상세의 📷 → 촬영 또는 갤러리 선택(여러 장 가능). 긴 변 1600px JPEG로 줄여 `첨부/<장소>-<시각>.jpg`로 커밋하고, 임장 메모에 `- 날짜 시각 (메모 칸 내용) ![[첨부/…jpg]]` 한 줄을 추가. Obsidian에서 그대로 보인다. 오프라인이면 대기열에 보관(브라우저 저장 공간 한도 안에서)했다가 연결되면 전송.

## 용도지역

상단 "용도" 버튼: 카카오 지적편집도(용도지역) 오버레이. 전국. 범례는 필터 패널.

## 정비구역 경계

- 상단 "구역" 버튼: 서울시 의제처리구역 중 정비 관련(재개발·재건축·재정비촉진지구·가로주택 등) 경계를 표시. 2천여 개라 레벨 7 이하로 확대했을 때 화면 안 구역만 그림. 구역을 누르면 이름, 장소 상세에는 그 장소가 속한 구역
- 자료: 서울 열린데이터광장 OA-20957 (`zones.json`, 키 불필요). 서울 밖은 없음. 해제·완료 구역이 남아 있거나 최근 지정분이 빠질 수 있음
- 갱신: 새 zip을 받아 `python tools/make_zones.py <폴더>/shp파일/UPIS_C_UQ181 zones.json "UQ181, YYYY-MM"` → 이어서 단계 붙이기
- 진행 단계: `node tools/zone_status.cjs` — 정비사업 정보몽땅 사업장 목록(진행단계·대표지번)을 받아 지오코딩(배포 사이트에서 카카오 JS 키, Edge 필요)하고, 대표지번이 들어가는 구역(없으면 같은 이름·1.2km 안)에 단계를 붙인다. 완료(준공·이전고시·해산·청산)와 기록 없음은 기본 숨김, 범례의 버튼으로 회색 점선 표시. **매일 06:30(KST) GitHub Actions(`.github/workflows/zones.yml`)가 자동 실행** — 바뀐 단계가 있을 때만 커밋하고 Pages를 다시 빌드. 찾은 좌표는 `tools/geocache.json`에 쌓아 새 지번만 지오코딩. Actions 탭에서 수동 실행도 가능. 서울시 도시계획 자료는 사업이 끝나도 구역 결정 기록을 지우지 않아서 이 단계 정보가 필요하다

## 빌라 실거래

재개발 장소 상세의 "빌라 실거래": 구역 경계 안(경계 자료가 없으면 반경 300m)의 연립·다세대 실거래 — 거래가·대지권 평당·전용 평당 중위, 최근 거래 목록(누르면 지도에 표시), 같은 동 단독·다가구 토지 평당. 자료는 서울부동산정보광장(키 불필요), `node tools/villa_trades.cjs`가 진행 중 정비구역이 있는 관심 자치구 동의 최근 24개월을 받아 `villas.json`으로 저장(해제 거래 제외, 대지권은 분기 조회와 합침, 필지 좌표는 `tools/pnucache.json` 캐시). 매일 06:30 Actions가 단계 갱신과 함께 실행. 2018년 이후 준공은 신축⚠ 표시(권리산정기준일 확인).

## 아파트 실거래 · 수익 계산 · 로드뷰

- **아파트 실거래·전세**: `node tools/apt_trades.cjs`가 관심 13개 구 전체 동의 최근 36개월 아파트 실거래(해제 제외)와 최근 12개월 전세 신규 계약(갱신 계약은 5% 상한이라 제외)을 `apts.json`으로(단지 좌표·네이버 단지 코드 포함, 매일 Actions). 아파트·재건축 장소 상세에서 이름·거리로 단지를 찾아 평형별 3년 추이 그래프(파란 점=매매, 주황 선=월별 중위, 초록 점=전세), 최근 거래, 1년 전 대비 변화, 전세 중위·전세가율·갭(최근 6개월 중위끼리), 네이버 단지 매물 바로가기, "노트 시세 갱신" 버튼. 지도 라벨에 최근 거래가
- **새 거래 배지**: 장소마다 마지막으로 본 최신 실거래일을 폰에 기억. 그 뒤 거래가 생기면 마커 오른쪽 아래 주황 **N**, 목록에 "새 거래". 상세를 열면 새 거래 줄에 NEW가 붙고 배지는 사라짐. 빌라 실거래 목록도 지난번에 연 뒤 거래에 NEW
- **수익 계산**(재개발·재건축 상세 🧮): 매입가·감정가·비례율·조합원 분양가·기타 비용·전세·입주 시 시세 → 권리가액·프리미엄·분담금·총 투자·초기 현금·예상 차익. 노트 본문에서 비례율·조합원 분양가를 찾아 미리 채우고, 입력은 장소별로 폰에 저장, 결과를 임장 메모로 저장 가능
- **로드뷰**(🛣️): 장소 120m 안의 카카오 로드뷰를 전체 화면으로

## 주변 시설 · 거리 재기 · 지형도 · 비교

- **주변**: 장소 상세에 가까운 지하철역 3곳(1.5km), 가장 가까운 초·중·고(2km), 대형마트, 500m 안 학원·어린이집·병원 수, 300m 안 편의점 수. 카카오 장소 검색(키 불필요, 앱의 JS 키 사용). 거리는 직선, 도보 시간은 직선×1.3 ÷ 분속 67m로 어림. "지도에 표시"로 역·학교·마트 위치
- **거리 재기**(지도 오른쪽 아래 📏): 지도를 누를 때마다 점 추가, 총거리·도보·자전거 시간. ↶ 마지막 점 지우기, ✕ 끝
- **지형도**(⛰️): 카카오 지형 음영 오버레이 — 언덕·경사 확인용. 켬/끔은 기억
- **비교**(상세의 ⚖️ 비교 담기, 최대 4곳): 왼쪽 아래 "⚖️ 비교 N" → 노트 시세·최근 실거래·1년 변화·전세·전세가율·갭·준공·세대·정비 단계·가까운 역·초등학교를 한 표로. 줄마다 유리한 칸을 초록으로

## 좌표 채우기

좌표 없는 장소의 상세에서 "위치 후보 찾기" → 이름이 맞는 정비구역 경계(중심점)와 카카오 주소·장소 검색 결과를 지역 중심에서 가까운 순으로 보여줌. "보기"로 확인 후 "저장".

한꺼번에 채우기(PC): `KAKAO_REST_KEY` 환경변수에 카카오 REST 키를 두고 `python tools/fill_coords.py`(미리보기) → `--apply`로 노트에 기록. 주소는 지번·도로명까지 맞은 결과만, 이름 검색은 이름이 맞고 지역 중심 5km 안일 때만 채택. 기록 후 노트 저장소에서 커밋.

## 로컬 실행

```
python dev.py            # http://localhost:8000
```

localhost에서는 GitHub 대신 `dev.py`가 노출하는 로컬 노트 폴더(기본 `~/Documents/Ian_obsidian/임장`)를 읽는다. 지도까지 보려면 카카오 콘솔 → 앱 → 플랫폼 → Web에 `http://localhost:8000`을 추가해야 함(없으면 지도 없이 목록만).

## 마커

- 아이콘 = 유형: 아파트(건물), 재건축(건물+화살표), 재개발구역(점선 네모 안 집), 도시형생활주택(집), 미확인(?)
- 색 = 금액대(기본) 또는 평가 — 필터 패널 맨 위 "마커 색"에서 전환

| 금액대 | 1~5억 | 5~10억 | 10~15억 | 15~20억 | 20~25억 | 25억~ | 시세 없음 |
|---|---|---|---|---|---|---|---|
| 색 | 짙은 초록 | 연두 | 노랑 | 주황 | 빨강 | 보라 | 회색 |

- ✓ 다녀옴, ★ 1순위(금액대 색일 때). `제외`는 흐리게. 확대하면 이름 라벨

## 토지이음

장소 상세의 "토지이음": 노트 주소(괄호 속 지번 포함, 없으면 좌표)를 카카오 지오코더로 지번화해 PNU(법정동 10 + 산 1 + 본번 4 + 부번 4)를 만들고 `eum.go.kr/web/ar/lu/luLandDet.jsp?isNoScr=script&mode=search&pnu=…`를 연다. 못 만들면 토지이음 첫 화면.
